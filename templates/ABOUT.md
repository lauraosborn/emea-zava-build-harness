## Local AI

This application performs all AI inference **locally on-device**. No data leaves your device.

| Indicator | Description |
|---|---|
| Model in use | The model currently loaded for inference |
| Local AI status | Whether on-device inference is active |
| NPU utilisation | Live NPU usage while inference runs |
| Token generation progress | Streaming token throughput (where applicable) |

These indicators are surfaced in the main application UI so it is always clear
when AI inference is occurring.
